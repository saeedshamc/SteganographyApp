      Demo — how it works
      
        
        
          
      1. 
            Hide a small demo script (see test-fixtures/demo/) inside a PNG or PDF with a password.
          
        2. 
          
      2. 
            Open the cover in your normal viewer — it still looks like a normal image/PDF. Stego data is not executed there.
          
        3. 
          
      3. 
            Come back to the Extract tab, enter the password, and recover the file.
          
        4. 
          
      4. 
            If the payload is a program/script, you may Run it here after an explicit confirm — so everyone can see each step.
          
        5. 
        
      
        
      
          Open Stego is open-source and educational: the path is visible on purpose. There is no silent auto-run when you double-click a cover in the OS.

      Why don't Photos/Acrobat run the payload?
      
          
      
            They only interpret their own format. Stego bytes stay opaque until Open Stego decrypts them with your password.

      About
      
        
      
          Open Stego hides encrypted payloads in everyday files so you can study how steganography works —
          same format on CLI and GUI.
        
      
        
        
          
      • Method A: keyed LSB in PNG/BMP
        • 
          
      • Method B: keyed EOF append for other covers
        • 
          
      • Argon2id profiles + optional keyfile; AES-256-GCM
