About

        

          Open Stego hides encrypted payloads in everyday files so you can study how steganography works —
          same format on CLI and GUI (docs/FORMAT.md).
        

        
    
          
  • Method A: keyed LSB in PNG/BMP
    • 
          
  • Method B: keyed EOF append for other covers
    • 
          
  • Argon2id profiles + optional keyfile; AES-256-GCM
