# Learning path

Suggested order for newcomers reading this repo:

1. `docs/THREAT_MODEL.md` — what the tool is for
2. `docs/CRYPTO.md` — password → keys → AES-GCM
3. `docs/FORMAT.md` — on-disk / in-image layout
4. `docs/EMBEDDING.md` — Method A vs B
5. `crates/stego-core/src/` — implementation mirrors the docs
6. `crates/stego-cli` and `apps/desktop` — thin shells over the core

Contributions that improve documentation clarity are as valuable as code.
